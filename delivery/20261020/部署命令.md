## 3. 校验配置并保存必要运行参数

```bash
nerdctl --namespace cmtf2 run --rm --pull=never \
  --name kong-config-check --user 0:0 -e KONG_DATABASE=off \
  -v /root/kong-3.9.3/kong.yaml:/tmp/kong.yaml:ro \
  --entrypoint kong kong-gateway:3.9.3 config parse /tmp/kong.yaml
```

必须出现 `parse successful`。临时容器清理 WARN 时检查 `nerdctl --namespace cmtf2 ps -a --filter name=kong-config-check`，仅在仍存在时删除该临时容器，不操作其他容器。

```bash
umask 077
mkdir -p /run/kong-3.9.3
nerdctl --namespace cmtf2 inspect cmtf2-kong-adapter |
python3 -c '
import json,pathlib,sys
env=json.load(sys.stdin)[0]["Config"].get("Env",[])
allowed={"NOCOBASE_VERIFY_TLS","SSL_CERT_FILE","REQUESTS_CA_BUNDLE",
 "STORAGE_CACHE_SECONDS","MAX_FILE_BYTES","ALLOWED_MIME_TYPES",
 "CONNECT_TIMEOUT_SECONDS","REQUEST_TIMEOUT_SECONDS","UPLOAD_TIMEOUT_SECONDS",
 "MAX_CONNECTIONS","LOG_LEVEL","SOURCE_SYSTEM"}
values={}
for item in env:
 k,_,v=item.partition("=")
 if k in allowed:
  if "\n" in v or "\r" in v: raise SystemExit("Invalid multiline environment")
  values[k]=v
values["SSL_CERT_FILE"]="/etc/cmtf2/adapter-ca/ca.crt"
values["NOCOBASE_VERIFY_TLS"]="true"
p=pathlib.Path("/run/kong-3.9.3/adapter.env")
p.write_text("".join(k+"="+v+"\n" for k,v in values.items()))
p.chmod(0o600)
print("Runtime settings saved; YAML credentials will take effect")
'
```

若现场另有自定义挂载/启动参数，先核对，不直接套用。编辑上传目录 adapter.yaml 中需要变更的位置后继续；不要输出 Token 到日志。

## 4. 停止、替换配置、重建容器

该节点会有短暂停机。仅升级 Kong 和 Adapter，不删除 MinIO/Redis、证书或业务数据。

```bash
systemctl stop cmtf2-container@cmtf2-kong.service
systemctl stop cmtf2-container@cmtf2-kong-adapter.service
systemctl is-active cmtf2-container@cmtf2-kong.service
systemctl is-active cmtf2-container@cmtf2-kong-adapter.service
```

两项应为 inactive。随后：

```bash
nerdctl --namespace cmtf2 rm cmtf2-kong cmtf2-kong-adapter
cat /root/kong-3.9.3/kong.yaml > /etc/cmtf2/kong/kong.yml
cat /root/kong-3.9.3/adapter.yaml > /etc/cmtf2/kong-adapter/nocobase.yaml
chown root:10001 /etc/cmtf2/kong-adapter/nocobase.yaml
chmod 640 /etc/cmtf2/kong-adapter/nocobase.yaml
chown root:10001 /etc/cmtf2/kong-adapter/ca.crt
chmod 640 /etc/cmtf2/kong-adapter/ca.crt
chmod 755 /etc/cmtf2/kong-adapter

nerdctl --namespace cmtf2 create --name cmtf2-kong-adapter \
  --pull=never --net host --workdir /app \
  --env-file /run/kong-3.9.3/adapter.env \
  -v /etc/cmtf2/kong-adapter/nocobase.yaml:/app/config/nocobase.yaml:ro \
  -v /etc/cmtf2/kong-adapter/ca.crt:/etc/cmtf2/adapter-ca/ca.crt:ro \
  kong-adapter:3.9.3 uvicorn app.main:app \
  --host 127.0.0.1 --port 8080 --proxy-headers --forwarded-allow-ips '*'

nerdctl --namespace cmtf2 create --name cmtf2-kong \
  --pull=never --net host \
  -v /etc/cmtf2/kong:/etc/kong:ro \
  -v /data/cmtf2/kong:/kong_prefix \
  kong-gateway:3.9.3 kong docker-start

systemctl start cmtf2-container@cmtf2-kong-adapter.service
systemctl start cmtf2-container@cmtf2-kong.service
sleep 5
systemctl is-active cmtf2-container@cmtf2-kong-adapter.service
systemctl is-active cmtf2-container@cmtf2-kong.service
nerdctl --namespace cmtf2 ps
```

已有 systemd 模板无需 daemon-reload。仅 restart 旧容器不会更新镜像或去掉旧 Token 覆盖，必须按上述重建。

## 5. 每台验收

按所在节点选择且只执行一条：

```bash
NODE=swductftdms91v.swd.hksarg   # 228
# NODE=swductftmon91v.swd.hksarg # 229
# NODE=swductftkmn91v.swd.hksarg # 230
```

```bash
curl --noproxy '*' -sS -i --max-time 15 http://127.0.0.1:8080/api/health/live
curl --noproxy '*' -sS -i --max-time 30 http://127.0.0.1:8080/api/health/ready
curl --noproxy '*' --cacert /etc/cmtf2/kong/tls/ca.crt \
  --resolve "$NODE:32443:127.0.0.1" -sS -i --max-time 30 \
  "https://$NODE:32443/api/health/live"
curl --noproxy '*' --cacert /etc/cmtf2/kong/tls/ca.crt \
  --resolve "$NODE:32443:127.0.0.1" -sS -i --max-time 30 \
  "https://$NODE:32443/api/health/ready"
```

live/ready 应为 200。ready 不代表所有业务工作流或存储验收。失败查：

```bash
journalctl -u cmtf2-container@cmtf2-kong-adapter.service -n 80 --no-pager
journalctl -u cmtf2-container@cmtf2-kong.service -n 80 --no-pager
```

用 YAML API Key 读取业务 checklist，不输出凭据：

```bash
nerdctl --namespace cmtf2 exec -i cmtf2-kong-adapter python - <<'PY'
import httpx
from app.settings import Settings
s=Settings.from_env()
assert s.nocobase_config_token, "Missing YAML token"
with httpx.Client(timeout=30, trust_env=False) as c:
 r=c.get("http://127.0.0.1:8080/api/new-licence-checklist",
         params={"office_code":"LORCHE"},
         headers={"Authorization":"Bearer "+s.nocobase_config_token})
 print("Checklist HTTP:",r.status_code)
 r.raise_for_status()
PY
```

鉴权成功仍需用户按实际 SIT 业务数据验证 Create/Update、附件上传下载；不要把开发测试记录 ID 直接用于 SIT。

## 6. 三台完成后从本机验证公共入口

```powershell
curl.exe --noproxy "*" -k -sS -i --connect-timeout 5 --max-time 30 "https://cmtf2sit.swd.hksarg/api/health/live"
curl.exe --noproxy "*" -k -sS -i --connect-timeout 5 --max-time 30 "https://cmtf2sit.swd.hksarg/api/health/ready"
```

`-k` 仅用于诊断；正式证书验收应移除或使用 `--cacert` 指定受信任 CA。本地节点通过但外部返回 Kong no Route 时，核对 Nginx 是否剥离 /api，以及是否仍负载到旧节点；本次包不修改 Nginx，不承诺未经现场验证的外部连通性。

后续仅改 adapter.yaml/kong.yaml：修改的是 /etc 下实际挂载文件，再重启对应服务即可，无需重建镜像。三节点验收完成后可删除 `/run/kong-3.9.3/adapter.env`。
